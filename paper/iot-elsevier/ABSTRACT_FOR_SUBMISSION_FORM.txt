Title
CR-SHE: Oblivious homomorphic aggregation for collusion-resilient search and analytics over encrypted multi-cloud IoT data

Abstract (241 words; 250 if hyphenated words are counted as two)
Internet of Things deployments replicate telemetry across independent clouds, and the data must stay encrypted once it leaves the device domain. Distributed-trust systems hide which records a query selects, but they operate on plaintext, stop at retrieval, or need server interaction. We present CR-SHE, in which retrieval and analytics are both oblivious to a coalition of up to t=n−1 colluding providers, over data encrypted under one owner's key, with no communication between providers. We show that a homomorphic layer is then necessary: an additively shared store cannot answer such queries locally. Each provider folds its share of the selection vector into encrypted columns and returns one ciphertext, so neither the matched set nor its size leaves the client. A precomputed fast path makes registered aggregates independent of record count, a two-round flexible path serves conjunctions and ad-hoc weights by dealing fresh shares, and a one-time-pad mask removes posting-list leakage at rest. We prove correctness and adaptive security against t=n−1 collusion and evaluate on two real IoT corpora. On 405,184 sensor records a registered aggregate costs 39 ms per provider regardless of record count, and four aggregates with their MACs return in one 132 kB ciphertext. Against one server holding the same encrypted columns, the trust split saves 1.8–2.9× in server work but over 3,000× in uplink, which is what a thin IoT client needs. A frequency attack recovering every non-temporal tag from an unmasked index recovers none from the masked one.

Keywords
